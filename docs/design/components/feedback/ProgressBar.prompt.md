Determinate progress for the album scan. Pair it with the Pinwheel — the wheel carries the personality, the bar carries the number.

```jsx
<ProgressBar value={62} label="Matching albums · 62%" />
```

Notes: 3px tall, pill radius, purple fill on a sunken track. Do not use Bootstrap's striped/animated variant — it implies indeterminate progress while showing a determinate value.
