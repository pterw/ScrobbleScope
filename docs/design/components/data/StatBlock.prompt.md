Numbers that matter. The serif figure is the brand's signature data treatment — mono for keys, serif for values.

```jsx
<StatBlock label="Total albums" value="128" bordered />
<StatBlock label="Longest streak" value="41" unit="days" />
```

Notes: group 3–4 in a row inside a bordered strip, or stack `bordered` blocks in a sidebar. Never put a stat block inside a stat block.
