Read-only metadata chips. Not interactive — if it can be clicked it's a PillGroup pill, not a Tag.

```jsx
<Tag>release: 2025</Tag>
<Tag variant="outline">≥10 plays</Tag>
<Tag variant="solid">2025-03-14</Tag>
```

Notes: always mono, always ≤ 3 words. A row of tags replaces the old "Filter applied" paragraph block on the results summary.
