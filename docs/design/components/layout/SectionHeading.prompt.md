Top of every page and major section.

```jsx
<SectionHeading
  eyebrow="Top albums · 2025 · play count"
  title="What"
  accent="pterw"
  description="Filtered to albums released in 2025."
  actions={<Button mono size="sm">Export CSV</Button>}
/>
```

Notes
- The purple italic `accent` carries the username or the emphasised noun. One per heading, never two.
- Serif only at 22px and up. Below that, use a mono eyebrow alone.
